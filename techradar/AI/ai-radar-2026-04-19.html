Parcae stabilizes looped models for scalable language learning

Parcae is a novel, stable looped architecture designed to address the instability issues in existing looped language models. It tackles these problems by constraining the spectral norm of injection parameters through a negative diagonal parameterization. This method allows for stable scaling of FLOPs, offering an alternative to increasing parameter count. Empirical results show Parcae achieving lower validation perplexity and improving quality metrics compared to large Transformer baselines with fixed parameters and data. Specifically, Parcae demonstrates that looping can be effectively used to scale compute at test-time.

Your RAG System Retrieves the Right Data — But Still Produces Wrong Answers. Here’s Why (and How to Fix It).

Despite a Retrieval-Augmented Generation (RAG) system successfully retrieving correct source documents, it can still produce factually incorrect answers. The root cause identified is the presence of conflicting context within the same retrieval window, causing the language model to select one piece of contradictory information. The work details this failure mode using a substantial local experiment. It outlines three production scenarios where this issue silently breaks the system. A simple, small pipeline layer offers a fix without requiring additional models, GPUs, or API keys.
