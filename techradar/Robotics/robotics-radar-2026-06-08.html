ROS Discourse General: Isaac Lab Teleoperation & Data Collection: Controlling the AgileX NERO 7-DoF Robotic Arm

This tutorial details implementing keyboard teleoperation and data collection for the AgileX NERO (7-DoF) robotic arm using NVIDIA Isaac Lab. Users can achieve multimodality by directly controlling the end-effector pose via a keyboard interface. The environment supports simulating a block-stacking, pick-and-place task. Furthermore, it allows collecting human demonstration data into HDF5 format compatible with Robomimic and replaying recorded trajectories for verification. The setup offers out-of-the-box support for both the AgileX NERO and PiPER robotic arms.

ROS Discourse General: Pre-built ROS2 Humble Windows SDK + Standalone RViz2 (No Toolchain Required)

Introduces two projects simplifying ROS2 development on Windows: Ros2Simple and Rviz2Windows. Ros2Simple provides a pre-compiled ROS2 Humble SDK allowing building applications via standard CMake without needing the complex native toolchain or `colcon`. Additionally, it supports cross-compiling to Linux and ARM-Linux for industrial use. Rviz2Windows offers a standalone RViz2 executable that runs by simply double-clicking, requiring no prior ROS2 installation or configuration. These tools are designed to ease rapid prototyping and educational use cases on Windows platforms.
