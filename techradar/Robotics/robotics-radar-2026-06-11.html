ROS Discourse General: EpisodeVault: open source tool to debug why your LeRobot model regressed

Introduces EpisodeVault, an open-source tool designed to debug model regressions when training LeRobot policies on changing datasets. It allows users to track dataset versions and analyze differences between them using commands like `diff`. The output details changes in episode counts, distribution shifts across tasks, and degradation in quality metrics. A "blame" command traces a specific trained model back to the exact dataset version responsible for its performance. This tool provides actionable insights into why model performance might have declined due to data variations.

MASK: Multi-Agent Semantic K-Scheduling for Risk-Sensitive 6G Robotics

Multi-Agent Semantic K-Scheduling (MASK) addresses the challenge of coordinating high-performance robotics within limited spectral bandwidths characteristic of 6G systems. MASK employs an Arbiter-Assisted Semantic Information Gating (A-SIG) mechanism to schedule only the top-K agents based on computed semantic importance scores, thereby enforcing hard access constraints. These prioritized observations are aggregated into a latent state using a self-supervised global encoder for policy generation. This approach allows the system to mitigate tail risks effectively even when data is sparse due to channel restrictions. Evaluations show MASK matches unconstrained baseline performance despite severe bandwidth limitations and proves resilient to packet erasures, validating semantic scheduling's importance.

arXiv - cs.RO

Model-based Optimization of Anguilliform Swimming Gaits for Soft Robotic Applications

A Soft Lamprey-Inspired Dual Environment Robot (SLIDER) was developed using Lighthill's theory to model fluid environment actions like vortex forces and viscous dissipation. A fast, nonlinear model was created for structural parameters such as tail size and body stiffness, with fluid-structure interactions solved implicitly. Pneumatic actuation allowed cross-comparison between the robot's computational simulations and physical testing in water. Results showed low-frequency swimming is dominated by resistance, while high-frequency swimming is influenced more by inertia. Co-optimization of a genetic algorithm was used to fine-tune the control pattern and caudal fin design for optimal tethered swimming speed.

arXiv - cs.RO

Embodied-R1.5: Evolving Physical Intelligence via Embodied Foundation Models

Introduces Embodied-R1.5, a unified Embodied Foundation Model (EFM) designed for general physical intelligence by integrating cognition, task planning, correction, and pointing. It utilizes three automated data pipelines to build a large-scale dataset exceeding 15B tokens, employing a multi-task balanced RL recipe. A novel Planner-Grounder-Corrector (PGC) closed-loop framework allows the model to autonomously execute and correct long-horizon tasks. Despite having only 8B parameters, Embodied-R1.5 achieves state-of-the-art results on most embodied VLM benchmarks, outperforming major competitors. The researchers open-source the model weights, datasets, code, and an evaluation kit to advance research in EFMs.

arXiv - cs.RO

HiPi: Reproducible High-Fidelity Piezoresistive Sensors for Robotic Manipulation

HiPi is a novel, reproducible system designed to bridge the gap between easily fabricated piezoresistive sensors and high-fidelity readout capabilities for robotics. The system achieves this by designing an entire hardware stack focused on reproducibility, including a commercial PCB-compatible readout board and low-cost MCU module. It features optimized communication enabling 220 Hz readout across four dense tactile arrays in a bimanual setup. Testing with 3D-printed contact patterns demonstrated HiPi significantly improves contact geometry preservation compared to existing reproducible methods, increasing the average IoU from 0.428 to 0.797. These advancements enhance the practicality of using dense piezoresistive sensing for complex multi-fingered robotic manipulation.

arXiv - cs.RO

PLUME: Probabilistic Latent Unified World Modeling and Parameter Estimation for Multi-Finger Manipulation

PLUME introduces a world model designed to handle uncertainty in multi-finger manipulation tasks by jointly learning dynamics and an evolving belief over physical parameters. It utilizes a latent space to represent various physical parameters and rewards, which are functions of partially-observable variables. The proposed framework efficiently aligns the world model to true system dynamics through online parameter inference, circumventing the need for re-training. Evaluations on tasks like screwdriver turning and valve turning demonstrate successful zero-shot transfer from simulation to hardware. PLUME outperforms existing state-of-the-art offline reinforcement learning and behavior cloning methods across these benchmarks.

arXiv - cs.RO

Dynamic Execution Horizon Prediction for Chunk-based Robot Policies

Modern robot policies often use action chunking, predicting and executing a fixed sequence of actions, which assumes a constant execution horizon. This assumption fails for fine-grained tasks needing continuous replanning because the open-loop operation is limiting. The proposed Dynamic Execution Horizon Prediction (DEHP) method addresses this by training a lightweight branch to predict the optimal execution horizon using online reinforcement learning. Crucially, DEHP keeps the underlying chunk policy frozen, ensuring compatibility with pre-trained models. Evaluations demonstrate that DEHP significantly boosts success rates on complex manipulation tasks by dynamically adjusting the prediction based on task stage.

arXiv - cs.RO

A Modular Dual-Camera Pipeline for Micro-Inspection Using Aerial Robots

Presents aerial\_micro\_inspection, a modular pipeline designed for inspecting small details from drones without needing dangerously close passes or pre-existing target geometry data. The system utilizes two cameras: a zoomed, gimbal-mounted camera for fine detail capture and a wide-field-of-view stereo camera for site surface acquisition and regional partitioning. A vision-based feedback loop compensates for drone motion as the inspection camera focuses on small areas of the larger surface. Evaluation in simulation and real-world tests successfully demonstrated robust coverage during disturbances, detecting caterpillars on trees and whiteflies in greenhouses. The open-source pipeline, built in ROS 2, is designed to be adaptable by modifying its segmentation and detection checkpoints.

Bridging the sim2real gap in the table tennis robot with a transformer-based ball states predictor

Robotic table tennis requires accurate, fast ball state prediction for robust high-speed control. Existing methods are limited by either complex physics modeling or the difficulty learning long-range temporal dependencies from data. Researchers propose a transformer-based framework that uses attention mechanisms to model these long-range correlations directly from observations. This system is trained using a large real-world dataset covering various player skill levels and ball cannon setups. A novel, plug-and-play strategy called Swap Predictor at Deployment (SPAD) replaces the simulator with the learned predictor during deployment, effectively reducing the sim-to-real gap.

arXiv - cs.RO

Steering Multirobot Behavior via Closed-Loop Affine Activation Editing

Introduces Closed-Loop Affine Activation Editing (CLAE), an inference-time framework for modifying frozen robot policies without retraining or risking catastrophic forgetting. CLAE treats behavior steering as a closed-loop problem, editing intermediate activations based on the robot's state, environment, and desired actions. It functions by training a sparse autoencoder on policy activations and using a lightweight RL-based policy to apply state-dependent affine edits. Validation on multi-quadrotor navigation demonstrated that CLAE can control individual robot velocity profiles during goal navigation. Furthermore, it successfully coordinated group behavior to maintain formations or generate entirely new behaviors, such as reducing camera exposure.

arXiv - cs.RO

Learning Object Manipulation from Scratch via Contrastive Interaction

Contrastive Reinforcement Learning (CRL) struggles with object interaction because contacts induce distinct changes in dynamic modes. Recognizing this difficulty, the work models manipulation dynamics as a piecewise-smooth Markov process exhibiting nonlinear reachability structures. To address this, Interaction-weighted Resampling (IWR) is introduced to perform interaction-aware resampling across pre-, during-, and post-interaction phases. IWR compels the learned representation to maintain mode boundaries critical for multi-modal planning. In simulations of diverse interactive tasks, IWR significantly improved performance over existing CRL methods, achieving a 19.8% average gain, and enabled a real-world robot air hockey agent with improved success rates.
